# Big Data Analytics Lab

Weekly practical work for the Big Data Analytics module.

## Labs

| Week | Topic | Contents |
|---|---|---|
| [Week 1](week-1/README.md) | Linux, HDFS and Hadoop MapReduce | Linux filesystem commands, HDFS exploration, WordCount scripts and screenshots |
| [Week 2](week-2/README.md) | Python MapReduce with `mrjob` | Unix-style counts, word-frequency analysis, local execution, Hadoop execution and reducer configuration |

## Repository structure

Each week's directory contains:
- `README.md` — objectives, workflow, commands and recorded results.
- `scripts/` — source code used in the lab.
- `screenshots/` — evidence captured in the corresponding lab report.

Large input datasets are not included unless explicitly required. See each week's README for prerequisites and reproduction notes.
