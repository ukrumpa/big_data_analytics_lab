# Big Data Analytics Lab

Weekly practical work for the Big Data Analytics module.

| Week | Topic | Contents |
|---|---|---|
| [Week 1](week-1/README.md) | Linux, HDFS and Hadoop MapReduce | Filesystem commands, HDFS exploration and WordCount |
| [Week 2](week-2/README.md) | Python MapReduce with mrjob | Local and Hadoop word-count jobs |
| [Week 4](week-4/README.md) | Apache Spark and PySpark | DataFrames, Spark SQL, word count and Random Forest regression |

Each week contains a README, scripts and supporting screenshots. Large input datasets are not committed unless explicitly required.
